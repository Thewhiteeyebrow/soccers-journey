# Soccer's Journey: The Five Functions

Static site for soccersjourney.com. One page, no build step.

- `index.html` is the whole map (content lives in the data block at the top of the script).
- `og.jpg` is the link preview image, `icon.png` the home-screen icon.

Deploys to Vercel automatically on push to `main`.

Live at https://soccersjourney.com
